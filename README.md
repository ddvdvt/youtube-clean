# Видео без мусора

**Статус: 1.0.0, готово к отправке в Chrome Web Store.** Тексты карточки, ответы для проверки, скриншоты и промо-картинки лежат в [`store/`](store/). Перед отправкой нужно заменить адрес сайта `BASE` в [`extension/lib/brand.js`](extension/lib/brand.js) и `homepage_url` в манифесте (см. «Страницы на сайте автора»).

Расширение для Chrome и Edge, которое убирает с YouTube то, что отвлекает: Shorts, рекомендации на главной и рядом с видео, конечные заставки, автовоспроизведение, игры, раздел «Навигатор» и рекламные места в интерфейсе. Есть три готовых режима, фокус по расписанию и мягкое напоминание о времени.

Сейчас нишу держит Unhook (около миллиона пользователей). Главная жалоба на такие расширения — они ломаются, когда YouTube меняет вёрстку, и долго не чинятся. Поэтому здесь всё построено вокруг быстрой починки: правила лежат в одном файле данных, расширение само замечает, что правило перестало срабатывать, и умеет (если вы разрешите) подтянуть исправленные правила без новой версии.

## Возможности

Каждый пункт — отдельный переключатель в попапе или на странице настроек.

| Пункт | Что делает | «Минимум» | «Фокус» (по умолчанию) | «Только подписки» |
|---|---|:-:|:-:|:-:|
| Скрыть Shorts | полки на главной и в подписках, пункт меню, вкладка канала, Shorts в поиске и рядом с видео | ✓ | ✓ | ✓ |
| Shorts в обычном плеере | `/shorts/ID` → `/watch?v=ID` (по прямой ссылке, по клику и при переходах внутри сайта) | | ✓ | ✓ |
| Рекомендации на главной | вместо ленты — спокойная пустая страница с подписью | | ✓ | ✓ |
| Главная → Подписки | логотип и «Главная» открывают подписки | | | ✓ |
| «Следующее» справа от видео | колонка рекомендаций; плейлист остаётся | | ✓ | ✓ |
| Конечные заставки и подсказки | карточки поверх видео, стена роликов в конце, сетка в полноэкранном режиме | | ✓ | ✓ |
| Автовоспроизведение | выключается для каждого нового видео; если вы включили его сами — расширение не мешает | | ✓ | ✓ |
| «Навигатор» и «В тренде» | раздел меню | ✓ | ✓ | ✓ |
| Игры (Playables) | пункт меню и полки | ✓ | ✓ | ✓ |
| Рекламные места в интерфейсе | баннер над сайтом, промо в ленте и поиске, блок спонсора рядом с видео, магазин канала. **Только оформление**: сетевые запросы не блокируются, реклама в плеере не трогается — это не блокировщик рекламы | ✓ | ✓ | ✓ |
| Комментарии | — | личный выбор | | |
| Чат трансляций | — | личный выбор | | |

Режим переключает все пункты, кроме комментариев и чата.

- **Фокус по расписанию.** В выбранные дни и часы (интервал может переходить через полночь) к вашим настройкам добавляется «Фокус». Он только скрывает больше и ничего не возвращает. Переключение происходит само, без перезагрузки страницы.
- **Напоминание о времени.** Считается время, пока вкладка YouTube видна и активна; после заданного числа минут за день внизу страницы один раз появляется ненавязчивая подсказка. Счётчик хранится только на этом устройстве.
- **Пауза.** Главный переключатель «Включено» возвращает YouTube как есть.
- **Счётчик** «Скрыто на этой странице» в попапе.
- Интерфейс на русском и английском.

### Чего нет в версии 1.0 и почему

- **Оригинальные названия и звук вместо автоперевода / ИИ-озвучки.** Через интерфейс или адрес страницы это чисто не сделать: исходное название можно получить только отдельным запросом к серверам YouTube (oEmbed / внутренний API), а дорожку звука — только через недокументированный API плеера в контексте страницы. Это сетевые запросы и хрупкий код, что противоречит принципам расширения. Отложено.
- **Фильтр «ИИ-слопа».** Надёжного признака в разметке нет.
- **Мобильная версия `m.youtube.com`.** Только десктоп. Встраиваемые плееры (`youtube-nocookie.com`, iframe на других сайтах) не трогаются.

## Как это устроено (и почему легко чинить)

- **CSS прежде всего.** Все правила — в [`extension/config/selectors.json`](extension/config/selectors.json) (схема: [`selectors.schema.json`](extension/config/selectors.schema.json), версия и дата). Из него генерируется одна таблица стилей `селектор { display: none !important; }` ([`lib/config.js`](extension/lib/config.js) → `buildCss`). Контент-скрипт запускается на `document_start`, сразу применяет последнюю сохранённую таблицу стилей из кэша и только потом загружает модуль — поэтому ничего не «мелькает».
- **Минимум JS:** перенаправления (по адресу), выключение автовоспроизведения (клик по переключателю), проверка правил, счётчик времени. Переходы внутри сайта отслеживаются по событиям `yt-navigate-start` / `yt-navigate-finish`, `popstate` и раз в секунду по адресу — на случай, если YouTube переименует события.
- **Селекторы** опираются на имена компонентов (`ytd-reel-shelf-renderer`, `grid-shelf-view-model`), атрибуты (`page-subtype`, `is-shorts`, `tab-title`) и адреса ссылок (`/shorts/`, `/playables`), а не на случайные классы. Каждый селектор — отдельное правило, поэтому один непонятный браузеру селектор не ломает остальные.
- **«Возможно, YouTube изменил разметку».** У части правил есть «пробы» — что должно быть на странице данного типа, пока разметка прежняя (например, колонка рекомендаций на странице видео). После загрузки страницы расширение проверяет их (с повторами для элементов, которые подгружаются позже; не чаще раза в 10 минут на правило). Если правило не находит цель 5 раз подряд в течение хотя бы часа — в попапе появляется предупреждение, а в настройках видно состояние каждого правила. Ничего никуда не отправляется.
- **Чтобы починить правило:** поправить `selectors.json`, увеличить `version`, `npm test` → выпустить версию расширения и/или подписать файл для обновления по сети (ниже).

### Обновление правил по сети (по умолчанию выключено)

Почему выключено: без явного согласия расширение не делает ни одного сетевого запроса, и проверка в Chrome Web Store проще. Когда правило ломается, попап сам предлагает кнопку «Включить обновление правил».

- Адрес фиксированный и документированный: `BASE/rules/youtube-clean/selectors.signed.json` (см. `brandUrls().rules` в `lib/brand.js`). Файл раздаётся статически с сайта автора (GitHub Pages отдаёт `Access-Control-Allow-Origin: *`, поэтому дополнительных разрешений не нужно).
- Раз в сутки (и по кнопке «Проверить сейчас») файл скачивается без cookies, без редиректов, не больше ~260 КБ.
- Файл — **только данные**: `{format, version, config, signature}`. Подпись ECDSA P-256 / SHA-256 проверяется встроенным открытым ключом (`lib/remote.js`); затем конфиг проверяется по схеме (селекторы не могут содержать `{ } < @ ; \`, `url(`, комментарии). Используется, только если `version` больше встроенной. Иначе остаются встроенные правила. Код из сети не выполняется никогда.
- Выключили обновление — скачанные правила удаляются.

Подписать и выложить правила (нужен закрытый ключ `keys/rules-signing.pem`, он не в git — **сделайте резервную копию**; при потере придётся выпустить версию с новым открытым ключом через `node scripts/rules.mjs keygen`):

```
npm run rules:sign      # dist/rules/selectors.signed.json из extension/config/selectors.json
npm run rules:verify    # проверить подписанный файл встроенным открытым ключом
```

Загрузить `dist/rules/selectors.signed.json` на сайт в `rules/youtube-clean/`.

## Установка (распакованное расширение)

1. Скачайте или клонируйте репозиторий.
2. Откройте `chrome://extensions` (в Edge — `edge://extensions`) и включите «Режим разработчика».
3. Нажмите «Загрузить распакованное» и выберите папку `extension/`.

## Разрешения и зачем они нужны

| Разрешение | Зачем |
|---|---|
| Доступ к `https://www.youtube.com/*` | Скрывать выбранные части страниц YouTube и делать перенаправления. Других сайтов расширение не видит. |
| `storage` | Хранить настройки, состояние правил и счётчик времени локально. |
| `alarms` | Раз в сутки проверять обновление правил — только если вы включили эту функцию. |

## Конфиденциальность

Нет аналитики, рекламы и аккаунтов. История просмотров, поисковые запросы и время на сайте никуда не отправляются. По умолчанию — ни одного сетевого запроса. Подробнее — в [PRIVACY.md](PRIVACY.md).

## Страницы на сайте автора

После установки открывается вкладка `BASE/welcome/youtube-clean.html`, после удаления — `BASE/bye/youtube-clean.html`, ссылка «Другие расширения автора» ведёт на `BASE/#youtube-clean`, `homepage_url` — на `BASE`, правила для обновления — `BASE/rules/youtube-clean/selectors.signed.json`. Адрес `BASE` задан в одном месте: [`extension/lib/brand.js`](extension/lib/brand.js) (сейчас заглушка `https://USER.github.io/REPO/`). `npm test` проверяет, что `homepage_url` в манифесте совпадает с ним.

## Что проверено

- **Модульные тесты** (`npm test`, 48): настройки и режимы, расписание (в т. ч. через полночь), схема и валидация конфига, генерация CSS и экранирование, адреса и перенаправления, логика «правило сломалось», счётчик времени, подпись удалённых правил (подмена, чужой ключ, размер), сборка и проверка zip, требования Chrome Web Store.
- **E2E** (`npm run test:e2e`, 19 шагов) в установленном Chromium на **локальных** страницах, повторяющих DOM YouTube ([`e2e/fixtures/site.mjs`](e2e/fixtures/site.mjs): главная, видео, поиск, канал, Shorts, подписки, с переходами «как в SPA»).
- **Вручную на живом сайте** (без входа в аккаунт, десктоп, 26.10.2026): главная (лента скрыта, подпись показана, Shorts/«Навигатор»/игры/баннер скрыты), страница видео (рекомендации, заставки, сетка, блок спонсора скрыты; автовоспроизведение выключается при первой загрузке и при переходах; ручное включение уважается), поиск (полка Shorts и рекламный слот скрыты), канал (вкладка и полка Shorts скрыты), `/shorts/ID` → `/watch?v=ID`. Все пробы правил на живых страницах — «работает».
- **Не проверено вживую:** Shorts и реклама в ленте подписок и на главной у вошедшего пользователя, чат трансляции, Shorts в выдаче поиска одиночными роликами — только на локальных страницах.

npm run store:images  # скриншоты 1280×800 и промо-картинки в store/
