# Карточка в Chrome Web Store — русский

**Язык:** русский (ru). Английский вариант — в `listing.en.md`. Название и краткое описание берутся из `extension/_locales`.

## Название (из манифеста, 44 символа)

Видео без мусора — без Shorts и рекомендаций

Запасной вариант, если «Shorts» в названии не пропустят: **Видео без мусора — фокус без отвлечений** (тогда поменять `extName` в `scripts/locales.src.mjs` и выполнить `npm run locales`). Слово «YouTube» в названии не используется намеренно — совместимость указана в описании.

## Краткое описание (из манифеста, 121 символ из 132)

Скрывает Shorts, рекомендации, автовоспроизведение и лишние блоки на YouTube. Фокус по расписанию. Без аккаунта и слежки.

## Подробное описание

Открыли одно видео — через час обнаружили себя в ленте коротких роликов. «Видео без мусора» убирает то, что затягивает, и оставляет то, за чем вы пришли: поиск, подписки и сам ролик. Работает на YouTube в Chrome и Edge (десктоп).

Три режима — в один клик

• Минимум: без Shorts, игр, раздела «Навигатор» и рекламных мест в интерфейсе. Рекомендации остаются.
• Фокус: ещё и без рекомендаций на главной и рядом с видео, без конечных заставок и автовоспроизведения.
• Только подписки: как «Фокус», а главная сразу открывает ваши подписки.

Каждый пункт можно включить и выключить отдельно

• Shorts везде: полки, пункт меню, вкладка канала, ролики в поиске. Ссылки на Shorts по желанию открываются в обычном плеере — без бесконечной ленты.
• Рекомендации на главной: вместо ленты — спокойная пустая страница.
• Колонка «Следующее», карточки поверх видео, стена роликов в конце и сетка в полноэкранном режиме.
• Автовоспроизведение выключается для каждого нового видео. Включили сами — расширение не спорит.
• Комментарии и чат трансляций — по желанию.
• Рекламные места в интерфейсе — только оформление: расширение не блокирует запросы и не трогает рекламу в плеере.

Фокус по расписанию и напоминание

• В выбранные дни и часы строгий режим включается сам и выключается сам.
• Мягкое напоминание, когда за день набежало заданное число минут. Счётчик живёт только на вашем устройстве.

Быстро чинится

Сайт часто меняет вёрстку. Все правила лежат в одном проверяемом файле, а расширение само замечает, если правило перестало срабатывать, и пишет об этом в окне расширения. По желанию можно включить ежедневное обновление правил: скачивается только подписанный файл с данными, без кода.
