# Политика конфиденциальности «Видео без мусора»

_Дата: 26.10.2026_

## Какие данные обрабатываются

- **Страницы YouTube** (`www.youtube.com`). Расширение читает их структуру прямо в браузере, чтобы скрыть выбранные части, перенаправить Shorts и выключить автовоспроизведение. Что вы смотрите и ищете, никуда не сохраняется и не передаётся.
- **Настройки:** какие пункты скрывать, режим, расписание фокуса, напоминание, включено ли обновление правил.
- **Состояние правил:** для каждого правила — когда оно последний раз сработало и сколько раз подряд не нашло цель. Это только отметки времени, без адресов страниц.
- **Счётчик времени за сегодня** (одно число секунд и дата). Сбрасывается в полночь.
- **Скачанные правила**, если вы включили их обновление.

## Где хранятся данные

Только локально, в `chrome.storage.local` вашего браузера. Ничего не синхронизируется и не передаётся ни автору, ни третьим лицам.

## Сетевые запросы

По умолчанию расширение не делает никаких сетевых запросов.

Если вы включите «Обновлять правила с сайта автора», расширение раз в сутки (и по кнопке «Проверить сейчас») скачивает один файл `rules/youtube-clean/selectors.signed.json` с сайта автора:

- запрос идёт без cookies и не содержит ваших данных, настроек или истории;
- принимается только файл с данными (селекторы CSS), подписанный ключом автора и проверенный по схеме;
- код из сети не загружается и не выполняется.

Расширение не блокирует и не изменяет сетевые запросы YouTube.

После установки расширение один раз открывает вкладку с короткой инструкцией на сайте автора, а после удаления браузер открывает страницу с вопросом «почему удалили?». Это обычные статические страницы: расширение не добавляет к их адресам никаких данных или идентификаторов и ничего им не передаёт.

## Чего расширение не делает

- Нет аналитики, телеметрии, рекламы и учётных записей.
- Нет доступа к сайтам, кроме `www.youtube.com`.
- Не выполняется удалённый код.

## Удаление данных

«Сбросить настройки» на странице настроек удаляет настройки, состояние правил и скачанные правила. При удалении расширения браузер удаляет все его данные.
